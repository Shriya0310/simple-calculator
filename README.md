
# Simple Calculator

A simple command-line calculator built using Python 3.12.

## Requirements

- Python 3.12
- uv

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd simple-calculator
```

Run the project:

```bash
uv run simple-calculator
```

## Features

- Addition
- Subtraction
- Division

## Technologies Used

- Python 3.12
- uv
- Git and GitHub
